# User Management System

A lightweight, framework-free User Management app built with plain HTML, CSS, and JavaScript. Add, edit, and delete users from a simple list, or fetch a randomly generated user from a public API.

## 📖 About

This project was built to demonstrate core JavaScript concepts — DOM manipulation, event handling, array operations, and async API calls — without relying on any frameworks or libraries.
link :- file:///C:/Users/rasto/Downloads/user_management-main/index.html

## ✨ Features

- Add new users (name + email)
- Edit existing users
- Delete users from the list
- Fetch a randomly generated user via the randomuser.me API
- Responsive design (mobile and desktop)
- Simple input validation

## 🛠️ Tech Stack

- HTML5
- CSS3 (Flexbox, media queries)
- Vanilla JavaScript (no frameworks)
- [randomuser.me API](https://randomuser.me)

## 🚀 Getting Started

No installation or dependencies required — just a browser.

1. Clone the repository
```bash
   git clone https://github.com/Abhinavrastogi2/your-repo-name.git
```
2. Open `index.html` in your browser

That's it — the app runs entirely client-side.

## 🎮 Usage

- **Add a user:** Fill in the Name and Email fields, then click "Add User"
- **Edit a user:** Click "Edit" next to a user, update the fields, then click "Update User"
- **Delete a user:** Click "Delete" next to a user to remove them
- **Fetch a random user:** Click "Fetch Random User" to pull in a randomly generated person

## 🧠 Key Concepts Demonstrated

- DOM manipulation (`createElement`, `innerHTML`, `appendChild`)
- Event handling via `onclick`
- Array methods (`push`, `splice`, `forEach`)
- Async/await with the Fetch API
- Error handling with `try/catch`
- Responsive design using Flexbox and media queries
